About

This project was developed as part of the author's undergraduate thesis for the Bachelor of Computer Science (S.Kom) degree. The research focuses on Indonesian tweet emotion classification using a hybrid approach that combines Lexicon-Based features, IndoBERT embeddings, and a Convolutional Neural Network (CNN).

The repository is intended to document the research implementation and serve as a reference for students, researchers, and developers interested in natural language processing and emotion classification.

Although the project represents the final implementation of the thesis, it is designed to support future development. Potential improvements include experimenting with newer transformer models, optimizing feature fusion strategies, handling class imbalance more effectively, expanding the dataset, and exploring alternative deep learning architectures to improve classification performance.

Contributions, suggestions, and further research based on this project are welcome
